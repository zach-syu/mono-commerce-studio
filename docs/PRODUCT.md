# Product brief

User asks for a runnable, portable complete repo, Vercel frontend, Supabase backend, and an evidence-rich E2E HTML report with all generated outputs. Source: https://b23.tv/fXtoQPJ (Bilibili BV1XMbN6VEAf). Study its workflow; create independent layout and copy.

Flow: upload/use a sample → choose platform/language/category → assisted brief and editable selected copy sections → style/layout/resolution/output selection → coherent image set/detail page/banner/video → review/download/product library.

Four-step guided workbench chosen from three possible approaches: dense all-in-one dashboard (harder to start), chat-first creator (less precise review), focused steps with persistent preview (chosen, editable and predictable). This follows the user's authorization to design the interface autonomously.

Test coverage: food, beauty/wellness, apparel/accessories; banners; English and Japanese detail sets; library; empty upload/corrupt/oversize/unsupported image; blank prompt/copy selection; long copy; 4K; regeneration; network/provider errors; responsive keyboard interaction; actual downloads. Reports distinguish browser-composition E2E, Supabase E2E, live model calls, and mocked contract tests.

Data model: Product reference + verified facts → localized copy sections → output specs + style → generation records with actual dimensions, duration, provider, errors, and downloadable files. Source photo remains an immutable identity anchor. No invented certifications, prices, performance claims, or body/health results.
