## 不應混為一談的項目

- 主操作範例是草編鞋的 3 張參考照片，沒有看到相機商品的操作 Demo。
- 原始產品賣點文字框可修改；未觀察到每張規劃卡的獨立文案編輯操作。
- Banner 與日文詳情圖的完整生成不是影片已實測項目，屬本專案延伸。
- 畫面模型標示為「智能圖片 image」。不能推定它使用 Gemini 或其他指定模型。
- 影片沒有驗證後端、實際排隊時間、錯誤復原或照片真實商品一致性。

## 沿用目的，重新設計介面

保留「商品資料 → 規劃文案 → 選擇視覺 → 生成與檢查」的分階段思路。每張內容卡可改標題、內文、選取狀態。整套素材共用商品參考、色調與設定。來源影片的圖像目的可作規劃參考：白底主圖、品牌主視覺、核心賣點、材質結構、工藝細節、規格品質、使用情境、購買價值收束。

本專案使用自己的 Mono Studio 流程，並依使用者後續指定接入 CYBERBIZ Pitaya UI 元件。色彩、字型與元件依 `DESIGN.md` 記錄；預覽與資料流程仍以本專案需求安排。不複製影片來源的長左側表單、固定範例牆、商標、商品、文案或成品。

Banner 延伸為獨立輸出種類，保留同一商品 brief，另選 16:9 或 21:9 比例。後續可以增加手機獨立構圖、可見文字安全區及 CTA。這些是本專案設計建議，不歸因於來源影片。
