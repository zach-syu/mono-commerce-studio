怎麼免費試你的現有商品

  1. 回到文案頁，按「補齊 5 種用途」。原有文案會保留。
  2. 調整每張的用途、文案與畫面方向。
  3. 進入視覺設定，看「免費套圖預覽」。
  4. 按「免費預覽並下載」。免費模式則按「開始生成」。

自己的上傳圖不會替換成其他商品的照片。免費情境是構圖示意；只有範例商品才使用對應的既有場景。

  • 五種用途與五種版型、實際 PNG 像素、原圖來源、照片共用與手機版均有測試。
